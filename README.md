# AttieLab-QTL-Viewer

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

This resource provides an interactive R/Shiny web application for exploring quantitative trait loci (QTL) 
associated with mRNA traits in the Diversity Outbred mouse data reported in Opara et al.
- **Preprint**: <https://doi.org/10.64898/2026.03.06.710203>

> **Live application**: <https://connect.doit.wisc.edu/content/08a89532-32d3-4b0b-bff3-a16f3a05c926>

- **Software archive (Zenodo)**: <https://doi.org/10.5281/zenodo.19961001>
